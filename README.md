# Projects

A collection of academic and personal projects developed while building my programming and cybersecurity foundations.

## Projects

### 🔐 Port Scanner
A Python-based TCP port scanner using socket programming to identify open ports and perform basic network reconnaissance.

**Technologies:** Python, Socket, TCP/IP

### 🔑 Password Generator & Strength Checker
A Python command-line application that generates customizable passwords and evaluates password strength based on length and character composition.

**Technologies:** Python

### 🛡️ Authentication System
A C-based command-line authentication system featuring user registration, password strength validation, credential verification, and login attempt limits.

**Technologies:** C

### 🧾 Billing System
A C-based command-line billing application that handles product selection, quantities, total calculation, and CGST/SGST billing.

**Technologies:** C

### 📝 To-Do List
A Python command-line task management application that allows users to add, view, complete, and delete tasks.

**Technologies:** Python

**Concepts Used:** Lists, dictionaries, loops, conditionals, and user input
